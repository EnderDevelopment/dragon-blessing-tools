# Dragon Blessing Tools

Dragon Blessing Tools is a Minecraft plugin that adds four custom, unbreakable dragon-themed tools to your server: the Dragonfang Blade, Dragonclaw Pickaxe, Dragonscale Axe, and Dragonbreath Bow. Each tool is crafted with unique abilities, enchantments, and lore, and is marked with persistent data so the plugin can recognize them. The plugin includes commands to give players the tools and a menu to view them, plus listeners that trigger special effects such as dragon fire, extra drops, health leeching, and more.

## Install

1. Download the DragonBlessing.jar file from the releases page.
2. Place the JAR file into your server's `plugins` folder.
3. Restart your Minecraft server (or run `/reload confirm` if supported by your server software).

## Use

### Giving Dragon Tools

Use the `/dragonblessing` command to give yourself the dragon blessed tools:

```
/dragonblessing
```

To give the tools to another player, provide their name:

```
/dragonblessing <player>
```

You can also use the aliases `/db` or `/dragontool`.

### Viewing the Dragon Tools Menu

Use the `/dragontools` command to open the dragon tools menu:

```
/dragontools
```

This will display a list of all available dragon tools with their hover tooltips.

### Tool Abilities

The dragon blessed tools have special passive abilities:

- **Dragonfang Blade** (Netherite Sword): 30% chance to ignite enemies in dragon fire on hit.
- **Dragonclaw Pickaxe** (Netherite Pickaxe): 35% chance to drop extra ore blocks when mining.
- **Dragonscale Axe** (Netherite Axe): 25% chance to grant Speed I for 3 seconds when breaking blocks, and heals 1 heart per hit when used in combat.
- **Dragonbreath Bow** (Bow): Arrows create a small non-destructive dragon fire explosion on impact.

All dragon tools are unbreakable and have enchantments (Fire Aspect II, Efficiency V, Sharpness V, Flame I).
